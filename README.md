# 测评雷达

自动盯着你的 QQ 邮箱，把秋招测评通知里的**截止时间**抓出来，快到期时在桌面**弹窗提醒**。

- 数据 100% 存在本机（`data/radar.db` + `config.json`），不上传任何东西
- 只读邮箱，不发送、不删除、不改动任何邮件
- 授权码只存在本机 `config.json`

---

## 第一次使用（3 分钟）

### 1. 拿 QQ 邮箱授权码

1. 浏览器打开 **mail.qq.com** 并登录
2. 右上角 **齿轮 → 设置 → 账号与安全 → 安全设置**
3. 找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务**，点**开启**
4. 按提示做短信验证，页面给出 **16 位授权码**（先复制，关掉就看不到了）

> 授权码 ≠ QQ 密码。密码改动后授权码会失效，重新生成一个即可。

### 2. 启动

双击 **`启动测评雷达.bat`**。

浏览器会自动打开工作台（http://127.0.0.1:8765），按页面提示填邮箱地址和授权码，点「保存并测试连接」。通了之后工具立刻开始抓邮件。

### 3. 已经装好的两处入口（2026-10-28 部署）

| 位置 | 作用 |
|---|---|
| **桌面「测评雷达.bat」** | 双击启动，自动打开工作台 |
| **开机自启**（`shell:startup` 里的「测评雷达（开机自启）.bat」） | 开机 15 秒后静默启动，只出右下角悬浮条，不弹浏览器 |

关闭开机自启：`Win + R` 输入 `shell:startup`，删掉里面那个文件即可。

> 说明：这个工具**不适合发布到公网**。工作台没有登录鉴权，放到公网等于公开你的公司清单和截止时间；
> 而且 IMAP 抓取和桌面弹窗都依赖本机环境，云端跑不起来。它的正确形态就是"本机常驻 + 开机自启"。

## 日常怎么用

| 想做什么 | 怎么做 |
|---|---|
| 看所有测评和倒计时 | 打开工作台（悬浮条**双击**，或浏览器访问 `127.0.0.1:8765`） |
| 手动收一次邮件 | 工作台右上「检查邮件」 |
| 常驻提醒 | 桌面右下角的小黑条会一直显示**最近一个截止**的倒计时 |
| 快到期弹窗 | 到期前 **72 / 24 / 6 / 2 小时**各弹一次，弹窗里可直接「标记完成」 |
| **微信推送** | ⚙ 设置里勾选「微信推送」，填 PushPlus token（见下） |
| 退出程序 | 悬浮条**右键 → 退出** |

自动检查频率默认 **20 分钟一次**，可在工作台「⚙ 设置」里改。

## 微信推送（可选）

弹窗只在电脑开着时有效；想人不在电脑前也收到，可以开启微信推送。有两条官方路子：

### 方式一：企业微信群机器人（推荐）

官方功能、免费**不限条数**、消息直接出现在**个人微信**里。约 10 分钟，一次配好长期有效：

1. 手机装「**企业微信**」App，用微信扫码注册 —— **账号类型必须选「企业」**（选"个人团队"没有管理后台，消息到不了个人微信）
2. App 里 **通讯录 → 创建群聊 → 内部群**（外部群加不了机器人），只拉自己一个人
3. 进这个群 → 右上角 **···** → **群机器人** → 添加机器人 → 复制 **Webhook 地址**
4. 电脑打开 **work.weixin.qq.com** 管理后台 → 我的企业 → **微信插件** → 勾选「允许成员在微信插件中接收和回复聊天消息」→ 扫码关注

然后在工作台 ⚙ 设置 → 勾选「微信推送」→ 选「企业微信群机器人」→ 粘贴 Webhook 地址 → 点「发一条测试消息到微信」验证。

做完后，机器人消息会出现在你**个人微信**的「企业微信联系人」里。

### 方式二：PushPlus（2 分钟配好）

1. 浏览器打开 **pushplus.plus**，点「登录」用**微信扫码**
2. 登录后在「一对一消息」页面复制 **32 位用户 token**
3. 工作台 ⚙ 设置 → 勾选「微信推送」→ 选「PushPlus」→ 粘贴 token → 测试

消息出现在微信的**公众号会话**里（不是锁屏强提醒），是第三方服务，免费额度有限。

> 两条通道和桌面弹窗共用同一套 72/24/6/2 小时档位，不会重复轰炸。
> 不使用 itchat/wechaty 等逆向个人号的"微信机器人"，那类方案违反微信协议、有封号风险。

## 它怎么认测评邮件

- 主题/正文命中「测评、笔试、在线测试、assessment」等关键词，或发件人是北森、牛客、赛码、SHL、Moka 等测评平台
- 从正文里识别「截止时间：…」「请在 X月X日 18:00 前完成」「有效期 7 天」这类写法
- 每条记录都标注置信度：
  - 无标记 → 邮件里明写的日期+时刻，可靠
  - 🟠 **未写具体时刻** → 按当日 23:59 计
  - 🟠 **按有效期推算** → 邮件只说"7 天内"，按收到时间推算
  - 🟠 **已推算，建议核对** → 邮件压根没写截止时间，按收到后 48 小时推算（可改）
- 同一家公司发来延期通知时，自动更新成新的（更晚的）截止时间
- 邮件没抓到的，可以在工作台「+ 手动添加」

## 常见问题

**弹窗没弹？**
- 凌晨 0:00–7:00 是免打扰时段，不弹；白天会补弹
- 先在工作台点某条记录的「试弹窗」确认弹窗功能正常

**连不上邮箱？**
- 「测试连接」最多等 30 秒一定出结果，并显示卡在哪一步（连接 → 登录 → 读收件箱）
- 检查授权码是否完整（16 位）、有没有过期（改过 QQ 密码会失效）
- 确认 IMAP 服务已开启（见上面第一步）
- 提示"登录太频繁被临时限制"时，等 5–10 分钟再点，不要连着点

**页面上出现红色横条「本地程序已断开」？**
- 说明测评雷达进程退出了（电脑重启、被杀毒软件清理等），页面里点任何按钮都不会生效
- 重新双击 `启动测评雷达.bat` 即可；启动脚本如果检测到启动失败，会自动用黑窗口显示具体错误

**想开机自启？**
- 已经装好了（见上面「已经装好的两处入口」），无需再操作

**误抓了不相干的邮件？**
- 在工作台直接「删」掉那条即可，下次检查不会再来

## 文件说明

```
assessment-radar/
├── 启动测评雷达.bat          双击启动（后台运行，无黑窗口）
├── 启动（调试模式）.bat       出问题时用，能看到日志输出
├── app.py                    主程序（Web 服务 + 调度）
├── parser.py                 邮件识别 + DDL 提取规则
├── mailer.py                 QQ 邮箱 IMAP 客户端
├── notify.py                 微信推送通道（PushPlus / Server酱）
├── core.py                   配置 / 数据库 / 任务合并 / 倒计时口径
├── reminder.py               桌面弹窗 + 悬浮条
├── selftest_parser.py        解析规则自测（python selftest_parser.py）
├── config.json               你的配置（邮箱、授权码、推送 token 在这里）
├── data/radar.db             任务数据
└── data/app.log              运行日志
```
