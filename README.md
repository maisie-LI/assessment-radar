# 测评雷达

自动盯着你的 QQ 邮箱，把秋招测评通知里的**截止时间**抓出来，快到期时在桌面**弹窗提醒**。

- 数据 100% 存在本机（`data/radar.db` + `config.json`），不上传任何东西
- 只读邮箱，不发送、不删除、不改动任何邮件
- 授权码只存在本机 `config.json`（仓库里只有空白模板 `config.example.json`）
- **零第三方依赖**：只用 Python 标准库，不需要 `pip install`，也不需要管理员权限
- **规则可自定义**：抓取口径与时间语义都集中在 `parser.py` 的关键词表里，改词表就能换成别的提醒场景（见[自定义](#自定义改成任何有截止时间的提醒邮件)）

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（桌面弹窗和右下角悬浮条依赖 Windows） |
| Python | **3.11 及以上完整版**，从 [python.org](https://www.python.org/downloads/) 下载。安装时保持默认勾选（含 tcl/tk）；**不要用嵌入式精简版**——它不带 `tkinter`，程序起不来 |
| 网络 | 能连 `imap.qq.com:993` |

启动脚本会自动在以下位置找可用的 Python，找不到时退回系统 PATH 里的 `python`：
`%LOCALAPPDATA%\Programs\Python\Python311 ~ 314`。多个版本共存时，会自动挑**能 import tkinter** 的那个。

## 第一次使用（3 分钟）

### 0. 拿到程序

- **下载 ZIP**：页面右上角 `Code → Download ZIP`，解压到任意目录（路径含中文、含空格都没问题）
- **或者克隆**：`git clone https://github.com/maisie-LI/assessment-radar.git`

解压后目录里**没有** `config.json` —— 那是你自己的私密配置，不随仓库分发。不用手动创建：第一次打开工作台时按页面提示填邮箱和授权码，程序会自动生成；`data/` 目录也会在首次运行时自动创建。

### 1. 拿 QQ 邮箱授权码

1. 浏览器打开 **mail.qq.com** 并登录
2. 右上角 **齿轮 → 设置 → 账号与安全 → 安全设置**
3. 找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务**，点**开启**
4. 按提示做短信验证，页面给出 **16 位授权码**（先复制，关掉就看不到了）

> 授权码 ≠ QQ 密码。密码改动后授权码会失效，重新生成一个即可。

### 2. 启动

双击 **`启动测评雷达.bat`**。

浏览器会自动打开工作台（http://127.0.0.1:8765），按页面提示填邮箱地址和授权码，点「保存并测试连接」。通了之后工具立刻开始抓邮件。

### 3.（可选）做成桌面图标 / 开机自启

| 想要 | 怎么做 |
|---|---|
| 桌面图标 | 右键 `启动测评雷达.bat` → **发送到 → 桌面快捷方式** |
| 开机自启 | `Win + R` 输入 `shell:startup` 回车，把 **`启动（开机自启，静默）.bat` 的快捷方式**放进这个文件夹（开机 15 秒后静默启动，只出右下角悬浮条，不弹浏览器） |
| 取消开机自启 | 同上目录，删掉那个快捷方式 |

> 三个 bat 全部用 `%~dp0`（脚本自身所在目录）定位程序，**整个文件夹可以随便移动、复制到别的电脑**，不需要改任何路径。

> 说明：这个工具**不适合发布到公网**。工作台没有登录鉴权，放到公网等于公开你的公司清单和截止时间；
> 而且 IMAP 抓取和桌面弹窗都依赖本机环境，云端跑不起来。它的正确形态就是"本机常驻 + 开机自启"。

## 微信推送（可选）

弹窗只在电脑开着时有效；想人不在电脑前也收到，可以开启微信推送。有两条官方路子：

### 方式一：企业微信群机器人（推荐）

官方功能、免费**不限条数**、消息直接出现在**个人微信**里。约 10 分钟，一次配好长期有效：

1. 手机装「**企业微信**」App，用微信扫码注册 —— **账号类型必须选「企业」**（选"个人团队"没有管理后台，消息到不了个人微信）
2. App 里 **通讯录 → 创建群聊 → 内部群**（外部群加不了机器人），只拉自己一个人
3. 进这个群 → 右上角 **···** → **群机器人** → 添加机器人 → 复制 **Webhook 地址**
4. 电脑打开 **work.weixin.qq.com** 管理后台 → 我的企业 → **微信插件** → 勾选「允许成员在微信插件中接收和回复聊天消息」→ 扫码关注

然后在工作台 ⚙ 设置 → 勾选「微信推送」→ 选「企业微信群机器人」→ 粘贴 Webhook 地址 → 点「发一条测试消息到微信」验证。

做完后，机器人消息会出现在你**个人微信**的「企业微信联系人」里。

### 方式二：PushPlus（2 分钟配好）

1. 浏览器打开 **pushplus.plus**，点「登录」用**微信扫码**
2. 登录后在「一对一消息」页面复制 **32 位用户 token**
3. 工作台 ⚙ 设置 → 勾选「微信推送」→ 选「PushPlus」→ 粘贴 token → 测试

消息出现在微信的**公众号会话**里（不是锁屏强提醒），是第三方服务，免费额度有限。

> 两条通道和桌面弹窗共用同一套 72/24/6/2 小时档位，不会重复轰炸。
> 不使用 itchat/wechaty 等逆向个人号的"微信机器人"，那类方案违反微信协议、有封号风险。

## 它怎么认邮件（判定口径）

### 第一道筛子：动作词 × 对象词

| 类别 | 词表 |
|---|---|
| 动作词 | 邀请 / 参加 / 参与 / 完成 / 作答 / 答题 / 登录 / 进入 / 确认 |
| 对象词 | 测评 / 测试 / 笔试 / **面试** / 考试 / 评估 / 作答 |

两者必须**在同一句里构成搭配**（动作词后 28 字内出现对象词，或对象词前 10 字内有动作词）。全文各出现一次但离得很远的不算——否则"直播间""求职攻略""简历投递反馈"这类邮件会被误收。

### 第二道筛子：排除

- **主题**出现这些直接跳过：笔试结果 / 测评结果 / 面试结果 / 面试报告 / 录用通知 / 入职通知 / 宣讲会 / 招聘会 / 体检通知 / 满意度 / 感谢您 / 遗憾 / 未通过 / 退订 / unsubscribe
- **正文前 2000 字**出现这些判为拒信：遗憾 / 未通过 / 抱歉地通知 / 不再进入 / 未能进入 / 不符合任职（岗位、招聘）要求

> ⚠️ 「不符合要求」单独出现**不算**拒信——设备检测说明里常写"如不符合要求，请更换电脑设备"，早期版本因此误杀过整封测评邀请。

### 时间怎么分层（一封邮件里有多个时间时）

| 层 | 识别词 | 工作台颜色 | 是否当主截止 |
|---|---|---|---|
| ① 试考 | 试考 / 模拟考 / 设备测试 / 环境测试 / 候考 / 提前登录 | 橙 | 仅当前置、回执都没有时 |
| ② 前置任务 | 考点预约 / 准考证打印 / 上传 / 缴费 / 资料审核 | 橙 | ✅ 优先 |
| ③ 回执确认 | 回执 / 确认参加 / 反馈意愿 / 意向确认 | **紫，独立区块** | 仅当前两类都没有时 |
| ④ 正式考试 / 面试 | 笔试时间 / 考试时间 / 面试时间 / 开考 | **红，显示「开始 → 结束」** | 最后兜底 |

- 同一封邮件里 ①②③ 与 ④ 同时存在时，会**额外单列一条「正式笔试 / 面试时间」独立提醒**，自己单独走 72/24/6/2 小时四档——避免你盯着前置截止，却错过考试本身
- **纯时刻区间**也能识别：「19:00-19:15」取终点 **19:15**（真正的登录/交卷硬截止），不会只取到 19:00

### 截止时间从哪来（优先级从高到低）

| 顺序 | 来源 | 说明 |
|---|---|---|
| 1 | 邮件明写的日期 + 时刻 | 最可靠 |
| 2 | 邮件只写到日期 | 按当日 23:59 |
| 3 | 取邮件时间段的**终点** | 「有效期 10-28 至 11-13」→ 取 11-13 |
| 4 | 按邮件里的**时长**推算 | 「5 天内完成」= 邮件发送时刻 + 5 天，**保留原时刻**（10-26 17:59 → 10-31 17:59，不会强改成 23:59） |
| 5 | 按收件时间推算 | 邮件完全没写截止，按收到后 48 小时（`config.json` 里 `fallback_hours` 可改） |

每条任务都会在工作台上标出它属于哪一种；推算类的还会额外提示「建议提前 1 天完成」。

### 其他行为

- 同一家公司发来**延期通知**时，自动更新成更晚的截止时间，不会堆两条
- 邮件发出已超过 3 天、且截止时间已过 1 天以上的**历史邮件不入库**（避免一次性补录几十条过期项把工作台刷满）
- 邮件没抓到的，可以在工作台「+ 手动添加」

## 自定义：改成任何「有截止时间的提醒邮件」

这个工具真正在解决的问题是通用的：**从一封邮件里判断"要不要我做事" + "什么时候之前必须做完"**。这两件事的规律都在 `parser.py` 的关键词表里，与主流程解耦，**改词表就能换场景，不用碰调度、弹窗、数据库**。

所以同一套东西可以改成：

- 竞赛报名 / 夏令营材料提交截止
- 签证材料、政审材料、体检预约
- 宣讲会 / 双选会日程提醒
- 学费、房租、报销等周期性缴费提醒
- 任何"发件人会在邮件里写 deadline"的场景

### 改这几处就够（都在 `parser.py`）

| 想改什么 | 改哪个常量 |
|---|---|
| **哪些邮件该抓** | `_KW_ACTION`（动作词）+ `_KW_OBJECT_CN`（对象词）——例如把对象词换成 `报名`、`提交`、`缴费`、`材料` |
| 哪些邮件要排除 | `_HARD_NEG`（看主题）、`_BODY_NEG`（看正文前 2000 字） |
| 时间怎么分层 | `_KW_PRETEST`（试考）/ `_KW_SUB`（前置）/ `_KW_RECEIPT`（回执）/ `_KW_EXAM`（正式）/ `_KW_DEADLINE`（通用截止）/ `_KW_START`（开放时间） |
| 分层显示的中文名 | `fmt_events()` 里的 `{"sub": "前置任务", "exam": "考试", ...}` 映射 |
| 主截止怎么选 | `extract_ddl_full()` 里的 `actionable = [...]` 那一行的层级顺序 |

### 改完必做两步

```bash
# 1) 先跑自测，确认没把原有 22 个真实样本改坏
python selftest_parser.py

# 2) 把 parser.py 顶部的规则版本号加一版（第 19 行）
RULE_VERSION = "v7-2026-11-05"
```

改版本号的作用：程序**下次启动时自动用新规则重算已有待办**。它会先自动备份数据库（`data/radar.db.bak-时间戳-规则重算前`），只重算 `pending` 状态的条目，**你勾过的「已完成」和手动添加的条目一律不动**。

### 建议：把踩过的坑存成样本

`selftest_parser.py` 里的 `SAMPLES` 是一个样本列表，每个样本就是"这封邮件应该被认成什么"。把自己遇过的真实邮件加进去（**记得抹掉姓名、邮箱、通行证号等个人信息**）：

```python
dict(
    name="我的场景·报名截止写在正文最后一行",
    sender="组委会 <no-reply@example.com>",
    subject="【XX大赛】报名通知",
    body="请于2026年11月20日18:00前完成报名。",
    mail="2026-11-01 09:00",
    want_company="XX大赛", want_ddl="2026-11-20 18:00", want_conf="exact", want_is=True,
),
```

以后每次改规则先跑一遍，就不会出现"修好一个、弄坏三个"。

## 常见问题

**弹窗没弹？**
- 凌晨 0:00–7:00 是免打扰时段，不弹；白天会补弹
- 先在工作台点某条记录的「试弹窗」确认弹窗功能正常

**连不上邮箱？**
- 「测试连接」最多等 30 秒一定出结果，并显示卡在哪一步（连接 → 登录 → 读收件箱）
- 检查授权码是否完整（16 位）、有没有过期（改过 QQ 密码会失效）
- 确认 IMAP 服务已开启（见上面第一步）
- 提示"登录太频繁被临时限制"时，等 5–10 分钟再点，不要连着点

**页面上出现红色横条「本地程序已断开」？**
- 说明测评雷达进程退出了（电脑重启、被杀毒软件清理等），页面里点任何按钮都不会生效
- 重新双击 `启动测评雷达.bat` 即可；启动脚本如果检测到启动失败，会自动用黑窗口显示具体错误

**想开机自启？**
- 见上面「（可选）做成桌面图标 / 开机自启」，把自启 bat 的**快捷方式**放进 `shell:startup`

**双击 bat 提示「当前 Python 缺少 tkinter」？**
- 你装的是精简版/嵌入式版 Python，或者装了 Microsoft Store 版（它不带 tkinter）
- 到 [python.org](https://www.python.org/downloads/) 下载**完整版**重装，安装界面保持默认勾选（特别是 `tcl/tk and IDLE`）
- 本工具会自动在 `%LOCALAPPDATA%\Programs\Python\Python311~314` 里挑**能用 tkinter** 的那个版本，装了多个版本时会自己选对

**双击 bat 一闪而过、什么都没发生？**
- 改用 `启动（调试模式，看日志）.bat`，它会在黑窗口里前台运行并把错误打印出来
- 工作台页面显示「本地程序已断开」时，点任何按钮都不会生效，先重新启动程序

**把文件夹移到别的电脑 / 别的目录还能用吗？**
- 能。三个 bat 都用 `%~dp0` 相对定位，路径没有写死
- 但 `config.json` 和 `data/` 在你本机私有目录里，**不会跟着 git 走**。换电脑后需要重新填一次邮箱授权码（历史任务数据要迁移的话，把 `data/radar.db` 一起复制过去）

**误抓了不相干的邮件？**
- 在工作台直接「删」掉那条即可，下次检查不会再来

## 隐私说明

| 内容 | 存在哪 | 会上传吗 |
|---|---|---|
| QQ 邮箱地址、16 位授权码 | `config.json` | ❌ 已在 `.gitignore`，仓库里只有空白 `config.example.json` |
| 抓到的邮件内容、公司名、截止时间、你的完成记录 | `data/radar.db` | ❌ 整个 `data/` 已被忽略 |
| 运行日志 | `data/app.log` | ❌ 已忽略 |

工具只通过 IMAP **读取**收件箱，不发信、不删信、不标记已读、不改动任何邮件。所有网络请求只有两个方向：连你的邮箱、以及（可选）推送消息到你自己的微信。
