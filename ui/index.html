先接上你的 QQ 邮箱

只读取测评类邮件，不发送、不删除、不修改你的邮箱。授权码只存在本机 config.json 里。
  1. 浏览器打开 mail.qq.com 并登录
  2. 点右上角 齿轮 / 头像 → 设置 → 账号与安全 → 安全设置
  3. 找到 POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务，点开启
  4. 按提示做短信验证，页面会给出 16 位授权码（关掉就看不到了，先复制）

提醒方式
4 步拿到 Webhook 地址（约 10 分钟，配一次长期有效，官方免费不限量）：
1. 手机装「企业微信」App，用微信扫码注册 —— 账号类型必须选「企业」， 选"个人团队"没有管理后台，消息到不了个人微信
2. App 里 通讯录 → 创建群聊 → 内部群（外部群加不了机器人），只拉自己一个人
3. 进这个群 → 右上角 ··· → 群机器人 → 添加机器人 → 复制 Webhook 地址
4. 电脑打开 work.weixin.qq.com 管理后台 → 我的企业 → 微信插件 → 勾选「允许成员在微信插件中接收和回复聊天消息」→ 扫码关注
做完后机器人消息会出现在你个人微信的「企业微信联系人」里。
2 步拿到 token：浏览器打开 pushplus.plus → 右上角「登录」用微信扫码 → 在「一对一消息」页面复制那串 32 位用户 token，粘到上面。
消息会出现在微信的公众号会话里，是第三方服务，免费额度有限。
